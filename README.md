# 其乐样式助手

一个给[其乐](https://keylol.com)（Keylol）论坛用的油猴脚本。

**解决的问题**：看到别人帖子里好看的排版，不用去研究 BBCode 怎么写 —— 选中那段文字，点一下吸管，就存成自己的样式按钮，发帖时一点即用。

面向的是**不懂发帖代码的人**：全程不需要看到 `[color=#c3392b]` 这种东西（想改也随时能展开改）。

## 功能

### 吸取样式（浏览帖子时）

选中带格式的文字，选区右下角会冒出一个小吸管图标：

- 点一下 → 读出这段的 BBCode，可存成样式
- 拖一下 → 换个位置（记住的是**相对选区的偏移**，所以下次选中仍跟着走）
- 双击 → 回到默认位置

能识别的结构：其乐自定义标题 `[k0]`~`[k5]`、折叠块 `[collapse]`、引用 `[quote]`、代码 `[code]`、隐藏 `[hide]`、剧透 `[spoiler]`、折叠 `[spoil]`、飞行文字 `[fly]`、缩进 `[indent]`、列表 `[list]`，以及字号 / 颜色 / 背景色 / 加粗 / 斜体 / 下划线 / 删除线 / 字体 / 对齐等文字样式。

### 样式面板（发帖页）

- 按分组列出所有样式，**可拖拽排序**（也能拖到别的分组）
- 点一下套用到发帖框：选中文字就包裹，没选中就插空标签
- 支持快捷键绑定（如 `alt+1`）
- 按钮上的名字用**其乐真实 CSS 渲染**，所见即所得

### 新建样式

- 直接**粘贴一段现成代码**，自动拆成开始 / 结束标签
- 也能手填，改开始标签时结束标签**自动同步**（不用记配对）
- 实时预览，可切换「真实渲染 / 模拟外观」

### 其它

- 页面门禁：只在发帖 / 编辑 / 回复页注入面板，浏览帖子时只有吸管
- 记住元素：认不出的结构可以「教」一次，之后自动认
- 设置项：自动切纯文本、块级样式套整行、吸管开关、真实渲染总开关、刷新站点样式

## 安装

1. 先装 [Tampermonkey](https://www.tampermonkey.net/) 浏览器扩展
2. **[点此安装脚本](https://raw.githubusercontent.com/Fusanmu/keylol-style-helper/main/Keylol%E6%A0%B7%E5%BC%8F%E9%9D%A2%E6%9D%BF.user.js)** —— 装好 Tampermonkey 后点这个链接，会自动弹出安装界面，点「安装」即可
3. 如果没弹出安装界面（比如还没装 Tampermonkey）：右键链接选「另存为」把 `.user.js` 下载下来，再拖进 Tampermonkey 的「实用工具 → 导入」

## 使用提示

- 脚本写入的是 **BBCode**，所以发帖框要处于**纯文本模式**（脚本会自动帮你切，设置里可关）
- 块级样式（折叠块、引用、缩进这类）记得勾「块级样式」，否则会挤在行内

## 开发

脚本是**单文件**的，没有构建步骤，直接改 `Keylol样式面板.user.js`。

仓库里带一个离线演示页和一套冒烟测试（用 jsdom 跑，不需要真站账号）：

```bash
# 需要 jsdom
npm i jsdom

# 跑测试
NODE_PATH=./node_modules node demo/smoke-test.js
```

`demo/demo.html` 模拟了其乐发帖页（含编辑器结构、真实 BBCode 渲染、各类自定义标签），可以离线打开看面板效果。

## 说明

- 部分站点结构（如标题 `[kN]` 与 `h(N+1)` 的绑定关系、隐藏类标签的真实 class）是**从真站页面和 CSS 里抓出来的**，站点改版后可能失效
- 「真实渲染」依赖其乐帖子页的 CSS，但发帖页不加载那套样式，所以脚本内置了一份（设置里可「刷新站点样式」从真站重新拉取）
